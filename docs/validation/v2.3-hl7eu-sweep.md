# HL7 v2.3 validation sweep (hl7.eu)

Date: 2026-10-19. Branch: claude/v23-segments.

## Sources and method

- **Reference (field lists):** hl7.eu v2.3 per-segment pages, `https://www.hl7.eu/HL7v2x/v23/hl7v23segm<CODE>.htm`, all 110 segments.
- **Cross-check:** the Caristix HL7 v2.3 crawl (`codegen/spec/v2.3-segments.json`). Caristix pages render client-side, so the crawl is the only copy usable offline.
- **Method:** field count, data type, and repeatability compared per segment. Lengths and usage flags were not compared.
- **Caveat:** hl7.eu tables were read through a summarizing fetcher. Before any code change based on a row in this report, read the source page to confirm the row.

## Summary

- 110 segments checked. The field count matches across hl7.eu, the crawl and our class for 102 segments.
- **Count problems (fix first):** our classes carry fields the 2.3 tables do not define, and one class is missing a field the 2.3 tables do define. See section 1.
- **Type disagreements:** about 45 fields where hl7.eu and the crawl name different types. Most are ID vs IS, which may be summarizer noise. See section 3.
- **Repeat disagreements:** about 17 fields where the two sources disagree. See section 4.
- **Repeat gaps in our code:** 170 fields the crawl marks repeating but whose setter takes one value. See section 5.
