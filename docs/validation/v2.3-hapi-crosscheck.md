# HL7 v2.3 cross-check against HAPI (hapi-hl7v2)

Date: 2026-10-19. Source: https://github.com/hapifhir/hapi-hl7v2 (shallow clone, commit de15036),
module `hapi-structures-v23`, segment classes under `ca/uhn/hl7v2/model/v23/segment`.

## Method

- HAPI segment classes list each field as `this.add(Type.class, required, repeats, length, ..., "name")`.
  That is the field table: datatype, required flag, maximum repeats (1 = not repeating; 0 or -1 = unbounded),
  and length.
- `codegen/validate/hapi-v23.mjs` compares those values with `codegen/spec/v2.3-segments.json`. It reads
  only the field definitions and does not copy HAPI code.
- Naming-only datatype differences (CN/XCN, TN/XTN, AD/XAD, LA1/LA2/CM_LA1) are not reported.
- HAPI is dual licensed (MPL 1.1 / GPL). It is used here only as a fact source. This project is MIT, so
  generated code should not be derived from HAPI's Java source without a license decision.
